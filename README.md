# ♻️ Waste-Track
## Aplikasi Manajemen Pengumpulan Sampah Lingkungan

Waste-Track adalah aplikasi untuk mengelola pencatatan setoran sampah warga secara digital. Data utama yang digunakan adalah data warga, jenis sampah, dan log berat setoran. Pengguna aplikasi adalah pengelola bank sampah atau koordinator kebersihan lingkungan.

Program ini dikembangkan untuk memenuhi Tugas Besar Mata Kuliah Algoritma dan Pemrograman 2 dengan implementasi berbagai konsep algoritma dan struktur data seperti CRUD, Sequential Search, Binary Search, Selection Sort, Insertion Sort, statistik data, validasi input, serta modular programming.

# 📌 Fitur Program

Program Waste-Track memiliki beberapa fitur utama, yaitu:

1. Tambah Data Warga  
2. Ubah Data Warga  
3. Hapus Data Warga  
4. Tampilkan Data Warga  
5. Tambah Transaksi Sampah  
6. Sequential Search ID  
7. Sequential Search Nama  
8. Binary Search ID  
9. Binary Search Nama  
10. Selection Sort Berat Sampah  
11. Insertion Sort Berat Sampah  
12. Statistik Sampah Mingguan  
13. Validasi Input Data  
14. Pengelolaan Tanggal dan Minggu Transaksi

📈 Statistik Program
Program dapat menampilkan:

- jumlah warga,
- jumlah transaksi,
- total sampah mingguan,
- rata-rata sampah, berdasarkan minggu transaksi yang dipilih pengguna.

✅ Validasi Program
Program memiliki beberapa validasi seperti:

- data tidak boleh kosong,
- berat sampah harus lebih dari 0,
- minggu hanya 1–4,
- validasi data ditemukan/tidak ditemukan,
- validasi tanggal transaksi.
